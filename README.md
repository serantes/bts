# BTS – Book To Speech

> Local neural text-to-speech powered by [Kokoro-82M](https://huggingface.co/hexgrad/Kokoro-82M).
> Reads text, text files and EPUB books aloud, or exports them to FLAC/MP3.
> No cloud. No API key. Runs entirely on your machine.

---

## Features

- **Stream or export** EPUB books and plain-text files to FLAC/MP3.
- **9 languages**: Spanish, English (US/UK), French, Italian, Portuguese, Japanese, Mandarin.
- **40+ neural voices** from the official Kokoro-82M release.
- **Pronunciation dictionary**: fix mispronounced words with phoneme markup.
- **Spelling analysis** (`--analyze --ipa`): automatically build a dictionary with IPA phonemes for every unknown word, using any supported language for the phoneme lookup.
- **Resumable exports**: already-exported sections are skipped automatically.
- Lazy model loading — `--help`, `--list-voices` and `--section-list` respond instantly.

## Install

**System requirements:** Python 3.10–3.12, `ffmpeg` (playback and MP3 export),
`espeak-ng` (es/fr/it/pt), and `libhunspell` + a Hunspell dictionary for `--analyze`.

```bash
git clone https://github.com/serantes/bts.git
cd bts
./scripts/bts_init.sh          # creates .venv and installs bts with all extras
```

Or manually:

```bash
pip install -e ".[all,dev]"
```

## Quick start

```bash
bts "Hola, esto es una prueba."
bts --epub libro.epub                        # stream aloud
bts --epub libro.epub --output --format mp3  # export, one file per section
bts --txt story.txt --output story.flac
echo "Hello" | bts --lang us                 # pipe from stdin
bts --lang us -                              # read stdin explicitly
bts --epub libro.epub --analyze --ipa        # build a pronunciation dictionary
bts --help
```

## Pronunciation dictionary

Lines are `word|replacement`. If the replacement is IPA phonemes in brackets,
Kokoro uses them directly:

```
# Simple substitution
Sr|señor

# IPA phonemes (generated by --analyze --ipa, then corrected by hand)
Tolkien|[tˈɒlkiːn]
```

Build a dictionary automatically from your book:

```bash
# --ipa uses --lang for phonemes; --ipa LANG overrides the phoneme language
bts --epub libro.epub --lang es --analyze --ipa       # Spanish phonemes
bts --epub libro.epub --lang es --analyze --ipa us    # English phonemes for proper nouns
```
